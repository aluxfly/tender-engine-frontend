## 功能需求

### 1. 关键词筛选

**支持多关键词匹配：**
- 物联网卡、物联卡、SIM 卡、流量卡
- 布控球、移动布控、视频监控、安防监控
- 支持自定义添加关键词

**匹配模式：**
- 标题匹配（必须）
- 描述匹配（可选）
- 全文匹配（可选）

### 2. 行业分类筛选

**预定义分类：**
- 通信/物联网
- 安防/监控
- 电力/能源
- 政府采购
- 其他

### 3. 地域筛选

**筛选维度：**
- 省份（下拉选择）
- 城市（下拉选择，根据省份联动）
- 支持多选

### 4. 预算筛选

**筛选方式：**
- 最小预算（输入框）
- 最大预算（输入框）
- 预设区间（快捷选项：0-50 万、50-100 万、100-500 万、500 万+）

### 5. 时间筛选

**筛选维度：**
- 发布日期范围（日期选择器）
- 截止日期范围（日期选择器）
- 快捷选项（今天、本周、本月）

### 6. 搜索结果展示

**列表展示：**
- 项目名称（高亮关键词）
- 发布日期
- 预算金额
- 甲方名称
- 地域
- 查看原文按钮（跳转原始链接）

**支持操作：**
- 收藏项目
- 导出 Excel
- 设置推送提醒

---

## 技术实现

### 前端（dev-frontend）

**页面：** `/filter` 或 `/search`

**组件：**
- 筛选面板（左侧/顶部）
- 结果列表（主区域）
- 分页组件
- 导出按钮

**技术要求：**
- 响应式设计（支持手机端）
- 筛选条件 URL 参数化（支持分享）
- 筛选结果缓存（提升性能）

### 后端（dev-backend）

**API 接口：** `GET /api/projects/filter`

**请求参数：**
```json
{
  "keywords": ["物联网卡", "布控球"],
  "category": "通信/物联网",
  "province": "北京市",
  "city": "北京市",
  "minBudget": 0,
  "maxBudget": 1000000,
  "publishDateStart": "2026-04-01",
  "publishDateEnd": "2026-04-14",
  "page": 1,
  "pageSize": 20
}
```

**返回格式：**
```json
{
  "total": 100,
  "page": 1,
  "pageSize": 20,
  "data": [
    {
      "id": 1,
      "name": "项目名称",
      "publishDate": "2026-04-14",
      "budget": 500000,
      "company": "甲方名称",
      "province": "北京市",
      "city": "北京市",
      "sourceUrl": "原始链接",
      "matchedKeywords": ["物联网卡"]
    }
  ]
}
```

**数据库优化：**
- 添加关键词索引
- 添加地域索引
- 添加预算索引
- 添加发布日期索引
